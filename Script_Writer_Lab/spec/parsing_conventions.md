# 语料解析与算子约定(L-01/L-02/L-05 的判定依据;有歧义以此文件为准)

## 行分类(按非空行处理;非空行 = strip 后非空)

- **集标题**:`^第[0-9零一二三四五六七八九十百千]+集`;**章标题**:同构的 `章`。含集标题 → `n_episodes` 计数。
- **场次行**:`^场景[::]`,计数入 `n_scenes`。
- **对白行**:匹配 `^([一-龥A-Za-z]{1,8})[::].+`,且角色名 ∉ {场景},且行首不是 `【`。台词 = 冒号后部分。计数入 `n_lines`。
- **标记行**:含 `【钩子】`/`【悬念】`/`【反转】` 之一 → 记入 `hook_positions`;`【伏笔】`/`【回收】` 用于 D14。

## 统计口径

- `hook_position` = 该标记所在**非空行**序号(从 1 计)/ 非空行总数,保留浮点。
- `dialogue_ratio` = 全部台词字数 / 全文非空白字符数。
- `sent_len_*`:按 `。!?…?!` 切句,字数为句长;CV = 标准差/均值。
- `kind`:存在场次行 → `drama_script`,否则 → `novel`。
- `parse_script` 接受路径(`str|Path`,存在则读)或**直接文本**(不存在该路径则按文本解析)。
- `simhash`:64 位十六进制;同文同值;去重判同 = hamming 距离 ≤3。

## 退化算子的补充约定

- **D05** 内置种子词表(≥10 个常见 AI 套话);`Operator` 必须暴露 `.lexicon: list[str]`;`mined/slop_lexicon.yaml` 存在时合并。注入密度按 `severity.per_1k_chars` 带内由 rng 取值。
- **D08** 语义 = **注入**一句与原文已声明事实(年龄/时间线/地点/称呼)冲突的陈述,原句保留不删。
- **D14** 输入约定:文本中伏笔句带 `【伏笔】`、回收句带 `【回收】`;算子删除 `【回收】` 标记行(整行)。
- 所有 deterministic 算子:同 `rng_seed` 输出完全一致;不得删除超过输入 30% 的字符(D14 除外,它只删标记行)。
