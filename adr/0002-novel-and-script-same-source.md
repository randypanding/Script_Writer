# ADR-0002：小说与剧本同源双视图，Line 层是共同的戏剧真相

- 状态：accepted
- 日期：2025-01-01
- 影响层：A1 / A6

## 背景
业务上商家更愿意读小说（易读、可转发、可给老板看），制作团队需要剧本。
若两者各生成一遍，必然讲成两个故事，且反馈无法互相复用。

## 决定
`Line[]`（对白/动作/画外音）是共同真相。
- 小说 = `p6_prose`（LLM）在 Line 之上编织叙述层，**不得发明新事件**，必须输出 100% 覆盖的 `anchor_map`。
- 剧本 = `p7_render`（无 LLM）对 Line 的确定性格式化。
交付顺序：大纲 → 小说（商家确认）→ 剧本（制作执行）。

## 被否决的替代
| 替代 | 为什么否决 |
|---|---|
| 小说与剧本各自独立生成 | 两个故事、反馈不可复用、一致性无法机检 |
| 先写小说再从小说抽剧本 | 小说的叙述层会污染 IR；抽取是有损的，反向对齐会退化 |
| 只出剧本，让商家读剧本 | 商家读不进去 → 确认延迟 → 返工发生在剧本之后（最贵） |

## 对下游的约束
- `NOV-001`（Beat 覆盖率 100%）与 `NOV-002`（对白相似度 ≥0.7）为 block 级。
- 叙述视角/人称/文体是 `NarrativeVoice` 渲染参数（ADR-0003），改它只失效 p6/p7。
