# 网文"平均风格"蒸馏 · 内化指南

> 目标：把公开中文网络小说语料炼成可复现的"平均风格"，供本系统（NSC）把质量底层烘进生成。
> 语料：`qqceqqq/webnovel-chinese`（apache-2.0，公共许可），抽样 6 本 / 3267 章 / 约 1000 万字。
> 产物：`webnovel_avg_priors.yaml`（确定性数字）+ `style_judgments.yaml`（定性判断）。
> 原始语料已丢弃，不入仓库（仅保留本项目 `scripts/distill_stats.py` 可重跑）。

## 一、"平均风格"一句话画像

**热、密、快。** 强代入、重节奏、轻留白：热开场（对白/冲突起手），对白短促口语化且句句配动作神态标签，强 tell（内心直给 + 带体温旁白），金手指/反转作节奏引擎，章末惯例抛钩子，配角工具化。句子长短混搭总体绵长，段落"一段一大段"。

## 二、四个可信的确定性锚（可直接做阈值）

| 先验 | 数值（evidence 3267 章） | 内化到 | 建议用法 |
|---|---|---|---|
| 对白长度分布 | p50=16 / p85=48 / p98=116 字 | p5_dialogue 台词长度 | 台词封顶阈值约 48（p85），硬上限 116；单句禁止承载多层信息 |
| 对白密度 | 对话占全文约 23% | 小说稿叙述/对白比参考 | 剧本对白密度应显著高于此；小说稿留叙述余地 |
| 章末对白钩子 | 约 67% 章节以对白收尾 | p2/p3 cliffhanger | 收尾拍落在对白或悬念句，而非把事讲完 |
| 章首热开场 | 首句对白约 32%，但热开场占比更高 | p3 首拍 | 首拍 hook/conflict，禁环境铺陈；热开场为主流 |
| 章长 | 中位 3019 字 | 分集体量参考 | 一集小说稿体量参考 |

## 三、定性判断 → 生成旋钮（待按 ADR 采纳）

逐条见 `style_judgments.yaml`。核心落点：
- **p3_beatsheet**：首拍 hook/conflict 化；每集 ≥1 次反转/意外馈赠节拍；收尾拍抛钩子。
- **p5_dialogue**：台词短促 + 配动作/神态标签（≥60%）；每个常驻角色赋 1 个专属开口词；冲突升级用称呼降格制造张力。
- **p6_prose**：允许强 tell（心理直给 + 带体温评价性旁白）；句子以 25~85 字为主区间。
- **p1_bible**：给角色声音区分留下抓手（口癖/身份称谓可作区分手段）。

## 四、内化的两条路径

1. **确定性路径（推荐、可复现）**：把"对白长度上限""章末钩子""首拍冲突"等落成 `spec/checks` 规则 / profile 参数。因为**改 `spec/checks` severity 与 `profiles` 属资产层，需先 ADR**，这里以"建议海拔"给出，未擅自改动。
2. **反馈/检索路径（长期）**：语料蒸馏出的 exemplar 与规则走既有 `L0_observations → mining → 晋升` 链路，纳入 retrieval 池或 GEPA 训练信号；本批不作为现金流喂检索（避免原始文本入检索，遵守 `usable_as_example` 闸门）。

## 五、可复现

```bash
uv run python -m scripts.distill_stats \
  --corpus <语料.jsonl> ...               # 任意来源的 {title,chapter,text} jsonl
  --out spec/distill/webnovel_avg_priors.yaml
```
扩展新语料（换成短剧剧本语料如 SkyScript 的剧本正文）即可重新炼"另一种平均风格"。

## 六、对"工业化平均风格"的结论

本项目既定目标是**快速生产的平均风格**，而非个性化品味。这批验证的是：**网文平均风格是可被确定性表征、可被规则化约束、可重跑的**。无需人工品味校准——只要把上述先验/判断落成规则与参数，注入 Pass，即可稳定复现"热·密·快"的合格平均水平。原始语料可丢弃，蒸馏出的数字/判断/提示词引导即"资产"。
